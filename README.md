# 🤖 AI Student Study Assistant

## 📌 About the Project

AI Student Study Assistant is a simple Python-based application designed to help students create a personalized study plan based on their chosen topic and difficulty level.

## ✨ Features

- Enter any study topic
- Select difficulty level
- Generates a customized study plan
- Provides an AI-inspired study tip
- Simple and beginner-friendly Python project

## 🛠️ Technologies Used

- Python
- Conditional Statements
- User Input
- Basic AI concepts

## ▶️ How to Run

1. Download or clone this repository.
2. Open study_assistant.py.
3. Run the Python program.
4. Enter your topic and difficulty level.
